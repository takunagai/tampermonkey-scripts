# Telegram Custom Theme

[Telegram Web](https://web.telegram.org/k/)（K 版）の見た目を調整する。CSS だけを変え、ページの操作・データには触れない。

## 対象ページ

- `https://web.telegram.org/k/*`（Web K 版。Web A 版の `/a/` は DOM が違うため対象外）

## 機能

| 箇所 | 元の表示 | 変更後 |
|---|---|---|
| メッセージ列と入力欄 | 最大 696px | 最大 1000px |
| 各メッセージの幅 | 最大 480px（30rem）。文字数に応じて幅がばらつく | 列の 85%（最大 850px）にそろえる |
| ファイルの幅 | 最大 325px | 同上 |
| メッセージ間の間隔 | 2px（連続の最後の後は 6px） | 6px（連続の最後の後は 10px） |
| 受信・送信メッセージの内側の余白 | 上 4〜8px・左右 8px・下 5px 前後（中身の種類で異なる） | 上下 15px・左右 10px |
| 受信メッセージの上辺 | 角丸 | 角丸なし + 2px の上ボーダー（色は送信メッセージの背景色） |

- 幅の変更は幅 601px 以上の画面だけ。幅 600px 以下の画面とチャンネル（broadcast）では Telegram の指定のまま
- 幅と内側の余白を変えるのは、テキスト・返信・ファイル・リンクプレビュー付きのメッセージ。画像・動画・アルバム・ステッカー・大きな絵文字・丸い動画は、メディアの寸法に合わせた元の表示のまま
- 上辺の変更は受信メッセージのうち背景のあるものだけ。ステッカー・大きな絵文字・丸い動画・メディアだけのメッセージは元のまま
- 日付などの区切り表示は変えない。ボーダー以外の配色・フォントも変えない

仕組み（Telegram のクラス名・変数に依存する。Telegram 側の変更で効かなくなることがある）:

- 列の幅は Telegram が `<html>` のインライン指定で入れる変数 `--chat-width` で決まるため、これを `!important` で上書きする
- 各メッセージは `--max-width: 30rem` の上限を、Telegram 自身が広い画面用に持つ `85%` に戻す。メッセージの枠（`.bubble-content-wrapper`）は中身の幅に縮む指定なので、`width: 100%` で上限まで伸ばしてそろえる
- 内側の余白は、Telegram が子要素の margin で作っている余白を 0 にし、枠（`.bubble-content`）の padding に置き換える
- 上辺の角丸は Telegram の変数 `--border-start-start-radius` / `--border-start-end-radius` を 0 にして消す。キャプション付き画像なども枠と一緒に角が四角になる

## 権限と理由

| @grant / @run-at | 理由 |
|---|---|
| `GM_addStyle` | 上書き用の CSS をページに追加するため。CSS は固定の文字列で、ページの内容を読んだり埋め込んだりしない |
| `@run-at document-start` | 狭い幅で一瞬描画されてから広がる（ちらつく）のを避けるため、ページの読み込み前に CSS を入れる |

通信・保存・Cookie の読み書きは一切しない。

## インストール

[dist/telegram-custom-theme.user.js](../../dist/telegram-custom-theme.user.js) を開き、Tampermonkey のインストール画面で「インストール」。

## 止め方

Tampermonkey のダッシュボードでこのスクリプトを無効にしてページを再読み込みする。
